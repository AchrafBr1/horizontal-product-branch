# HPB Markup · Vite + React example

Editable HPB Markup source with live preview, the reference examples A–E, theme switch,
diagnostics list and click selection, using `<HpbDiagram>` from `@hpb/react`.

```bash
pnpm install
pnpm --filter @hpb/core --filter @hpb/react build
pnpm --filter @hpb/example-vite-react dev     # or: build / preview
```
