HPB Markup in plain HTML

One <script> tag, no build step. The bundle exposes window.HPB, renders HPB blocks on load and registers the <hpb-diagram> element.

1. Auto-render a <pre class="hpb"> block

Like Mermaid: every pre.hpb, code.language-hpb or .hpb block is replaced by its diagram when the page loads. Hover a branch to dim the others; click a node to log it below.

hpb "Product A — firmware line"
line A "Product A"
release v1.0 @2026-01
improvement I-21 "Faster pairing"
issue X-101 "Crash on boot"
release v1.0.1 merges X-101
issue X-102 "Wrong time after power cut"
task T-8 "Migrate logs"
release v1.1 @2026-03 merges I-21, X-102
improvement I-22 "Low-power mode"
issue X-103 "Menu translation"
release v1.2 @2026-05 merges T-8, I-22, X-103
Click a branch or a baseline.

2. Markdown-style fenced block

Markdown renderers emit <pre><code class="language-hpb">; that is picked up too.

hpb "Planning with a release gate"

3. The <hpb-diagram> custom element

Text content (or a src URL) goes in, an SVG in a shadow root comes out. It re-renders when its attributes or its text change and dispatches hpb-node-click.

hpb "DMS-4000: hardware revision" line RA "DMS-4000 Rev A" release v1.2 @2026-01 lab L-5 "Sensor board v2" step L-5 fail "EMC test" improvement I-30 "Low-power mode" step L-5 pass "EMC retest" release v1.3 release RevB hardware merges L-5, I-30 line RB "DMS-4000 Rev B" from RevB release v2.0 on RB use RA release v1.4 issue X-118 "Relay chatter" release v1.4.1 merges X-118 eos RA @2026-12
Click a branch or a baseline.

4. Loading a .hpb file with src

Needs the page to be served over HTTP (browsers block fetch on file://). From the repository root: npx serve . and open /examples/html/.

5. Render to a string

await HPB.render(id, code) resolves with { svg, diagnostics, bindFunctions }, as in Mermaid, without touching the page.
